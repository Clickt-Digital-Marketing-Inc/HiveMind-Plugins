## Platform cadence norms

| Platform | Cadence norm | Recommended posting days | Peak windows (user's local time) |
|---|---|---|---|
| LinkedIn | 3-5x/week | Mon, Tue, Wed, Thu, Fri (skip weekends) | 8-10am, 12pm |
| X (Twitter) | 3-10x/day | Every day | 9am, 12pm, 5pm |
| Instagram | 1-2x/day + stories | Every day | 11am-1pm, 7-9pm |
| TikTok | 1-4x/day | Every day | 12pm, 6-9pm |
| Facebook | 1-2x/day | Every day | 1-3pm |

These are norms, not rules. Offer them as labeled defaults at intake (e.g. "LinkedIn — 3x/week (norm: 3-5x/week)") and let the user pick.

|---|---|---|---|---|---|
| Text post | ✓ (best) | ✓ | caption-only | ✗ | ✓ |

At intake, only offer formats compatible with the chosen platforms.

## Per-platform spec sheets

### LinkedIn
- Length: up to 3,000 characters; first 210 characters show before "see more" — the hook must land there.
- Hashtags: 3-5, end of post.
- Links: put links in the first comment when reach matters; native content outperforms link posts.
- Media aspect ratios: image 1:1 (1200x1200) or 4:5 (1080x1350); video 1:1 or 16:9, under 90 seconds for best completion.
- Tone: professional but personal; first-person stories outperform corporate announcements.

### X (Twitter)
- Length: 280 characters per post; threads 5-15 posts, each must stand alone.
- Hashtags: 0-2 max; more reads as spam.
- Links: suppress reach; put them in a reply.
- Media aspect ratios: image 16:9 (1600x900) or 1:1; video 16:9 or 1:1, under 2:20.
- Tone: punchy, conversational, strong opinions; hooks are the whole game.

### Instagram
- Length: caption up to 2,200 characters; first 125 characters show before truncation.
- Hashtags: 3-8 in the caption or first comment.
- Links: not clickable in captions — "link in bio" only.
- Media aspect ratios: feed image 4:5 (1080x1350); carousel 1:1 or 4:5, 3-10 slides; reel 9:16 (1080x1920), 15-60 seconds.
- Tone: visual-first; the caption supports the media, not the reverse.

### TikTok
- Length: caption up to 2,200 characters, keep under 150 for readability.
- Hashtags: 3-5 including one niche tag.
- Media aspect ratio: 9:16 (1080x1920); 15-60 seconds; hook in the first 2 seconds.
- Tone: native and unpolished beats produced; talk like a person, not a brand.

### Facebook
- Length: no hard limit; under 250 characters gets the best engagement.
- Hashtags: 0-2; hashtags matter little here.
- Media aspect ratios: image 1:1 or 4:5; video 1:1 or 9:16 (reels).
- Tone: community-oriented; questions and discussion starters perform.

## Strategy rules

1. **Content pillars**: every batch maps to 3-5 recurring themes the user owns. Ask which pillar each post serves; if the user has no pillars yet, derive 3-5 from the voice profile's Positions section and confirm.
2. **Batching and queue**: plan in weekly batches (2-3 hours of work) that maintain a 1-2 week publishing queue. When the user picks a post count, note whether it fills 1-2 weeks at their cadence and recommend adjusting if it does not.
3. **Evergreen ratio**: aim for 60% evergreen content; leave queue gaps for real-time reaction posts.
4. **Content atoms**: one strong idea can become 5-10 atoms (quotes, stories, tips, data points) adapted per platform. If the user picks fewer ideas than posts, extract multiple atoms per idea rather than stretching thin material.
5. **Standalone captions**: every post must work without context — no "as I said yesterday".

## Hook formulas and anti-slop banned phrases

Favor authentic storytelling hooks, in this priority order:

1. "I was wrong about X" — admission + lesson.
2. "Last week Y happened" — specific recent story.
3. Contrarian take + receipts — "Everyone says X. Here's why they're wrong: [evidence]".
4. Specific-number lesson — "3 clients asked me the same question this month".
5. Open question to the niche — genuine question, not engagement bait.

**Banned phrases and patterns** (the writing prompt MUST list these as forbidden):
- "In today's fast-paced world" / "In the ever-evolving landscape of"
- "game-changer", "revolutionize", "unlock", "unleash", "elevate", "delve"
- "Let that sink in." / "Read that again."
- Emoji-bullet listicles (🚀✅💡 as bullets) unless the user's voice profile explicitly uses them
- Rhetorical-question openers followed by "Well, ..."
- Any sentence the user's voice profile lists under "never say"

## Cadence-to-weekday pattern table

Used to compute publish dates. Start from tomorrow, never today or the past. Interleave platforms when a batch spans several.

| Cadence chosen | Weekday pattern |
|---|---|
| 1x/week | Tue |
| 2x/week | Tue, Thu |
| 3x/week | Mon, Wed, Fri |
| 4x/week | Mon, Tue, Thu, Fri |
| 5x/week | Mon-Fri |
| 1x/day | Every day |
| 2x/day | Every day, two slots (use the platform's two peak windows) |
| 3x/day or more | Every day, spread across peak windows |

Assign posts to slots in order until the batch is exhausted. Record the slot as "n of total" plus the pattern name (e.g. "2 of 6 (Mon/Wed/Fri over 2 weeks)").
